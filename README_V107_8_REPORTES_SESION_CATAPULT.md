# v107.8 - Informes de sesión tipo Catapult por categoría

## Objetivo
Mejorar el informe de sesión para que se parezca a un reporte deportivo profesional de carga, usando solo datos reales de Orsomarso Performance.

## U20
El informe de sesión muestra un bloque tipo Catapult con:
- distancia total,
- Player Load,
- velocidad máxima,
- alta velocidad,
- sprint distance,
- ACC,
- DCC,
- sprints,
- RHIE,
- IMA,
- volumen,
- intensidad,
- participación,
- tabla individual.

## U17 / U15
Como estas categorías no tienen GPS Catapult, el informe usa solo combinaciones reales de:
- minutos,
- RPE,
- carga interna = minutos x RPE,
- wellness promedio,
- participación,
- alertas por wellness bajo o RPE alto.

## Reglas
- No se inventan métricas.
- GPS solo aparece para U20.
- U17 y U15 no muestran campos GPS.
- Los informes son documentos, no capturas de la aplicación.
