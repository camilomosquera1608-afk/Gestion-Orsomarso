# Archivo SQL histórico

Scripts de migración y notas por versión (v107–v132) movidos desde la raíz del repo.

Para instalación nueva o esquema consolidado, usar:

- `supabase/schema.sql`
- `supabase/sql/RUN_THIS_IN_SUPABASE.sql`

Los archivos `SUPABASE_V*.sql` en esta carpeta documentan cambios incrementales ya aplicados en entornos existentes.
